One original line, 123 characters, roasting the gadget I use every day —
the printer that only ever works when nothing is urgent:

> My printer only works when nothing is urgent; the moment a deadline
> appears, it comes down with a paper jam out of respect.

## Run it

```sh
node main.ts
```

`main.ts` validates the line (one line, 1–200 characters) and writes it to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The
output is deterministic: the same bytes on every run.
